# METROPOLIA

Protótipo digital desenvolvido em Unity com foco em educação fiscal, gestão pública e impacto social das decisões governamentais.


#  Sobre o Projeto

Metropolia é um jogo de simulação e tomada de decisões onde o jogador assume o papel de gestor de uma cidade.

O objetivo é equilibrar:

* arrecadação de impostos;
* investimentos públicos;
* felicidade da população;
* crescimento populacional;
* estabilidade social.

O projeto foi desenvolvido como atividade acadêmica voltada à educação fiscal, utilizando conceitos de:

* tributos;
* orçamento público;
* arrecadação;
* cidadania fiscal;
* investimentos públicos;
* impacto coletivo das decisões.

#  Funcionalidades

##  Sistema de investimentos públicos

O jogador pode investir em:

*  Saúde
*  Educação
*  Segurança

Cada investimento impacta diretamente:

* felicidade da população;
* crescimento populacional;
* orçamento da cidade.



##  Sistema de arrecadação de impostos

O jogador pode arrecadar impostos para aumentar o orçamento da cidade.

Porém:

* a arrecadação excessiva reduz a felicidade da população;
* isso cria equilíbrio entre arrecadação e bem-estar social.



##  Sistema de felicidade

A cidade possui um indicador de felicidade que:

* aumenta com bons investimentos;
* diminui em momentos de crise;
* influencia o estado geral da cidade.

Também existe uma barra visual de felicidade.



## Sistema populacional

A população cresce ou diminui de acordo com:

* qualidade dos serviços públicos;
* crises;
* investimentos realizados.



##  Consequências sociais

Caso o jogador não tenha recursos suficientes:

* a população perde felicidade;
* ocorrem crises sociais;
* a cidade entra em declínio.



## Sistema de Game Over

O jogo termina quando:

* a felicidade chega a 0;
  OU
* a população chega a 0.

Ao perder:

* uma tela de Game Over aparece;
* o jogador pode reiniciar a partida.

#  Como Executar o Projeto

##  Requisitos

* Unity Hub
* Unity 6
* Visual Studio Code
* .NET SDK



##  Passos

1. Clone o repositório:

```bash
git clone LINK_DO_REPOSITORIO
```

2. Abra o projeto na Unity.

3. Abra a cena:

```text
MenuScene
```

4. Clique em:

```text
▶ Play
```
